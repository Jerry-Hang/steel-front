# 钢铁前线 (Steel Front)

Rust + Vulkan 实现的二战题材 FPS tech demo（`winit` / `ash` / `glam`，无第三方游戏引擎）。

## 玩法

- **开始菜单**：任意键开始一局。
- **目标**：击杀每波全部敌人（跑远的敌人不算清空，必须全歼）。清空后 3 秒倒计时，下一波敌人更多、更快、更肉。
- **死亡**：被敌人攻击扣血，血量归零进入结算画面；按 `R` 重开一局（分数/波次清零）。
- **计分**：击杀 +10，清波奖励 +25。

## 操作

| 输入 | 行为 |
| --- | --- |
| 鼠标移动 | 视角（游戏中光标捕获，yaw/pitch） |
| 鼠标左键 / `Space` | 开火 |
| `W` `A` `S` `D` | 移动 / 轨道平移目标 |
| `Q` / `E` | 下降 / 上升 |
| `Tab` | 切换相机模式（轨道 ↔ 飞行） |
| 滚轮 | 轨道推拉距离 / 飞行前进后退 |
| 右键拖拽 | 飞行模式视角 |
| `R` | 死亡结算后重开 |
| `ESC` | 退出 |

## 运行

```bash
cargo run --release
```

## 验证

```bash
cargo build --release && cargo test
```

- 单元测试覆盖：武器/投射物、A* 寻路与 NPC 状态机、物理碰撞、光照数学、音频混音、
  网络序列化与环回、HUD 布局、波次生成/伤害结算/游戏状态机。
- 冒烟验证：后台运行 15–20 秒，日志 `VUID` 计数为 0、fps ≥ 200、
  `game: wave=` 序列随波次推进、击杀产生 `kill` 日志。
