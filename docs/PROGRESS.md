## 切档说明与已知噪声（2026-10-02，v6）

### 三次迭代，每次都以为对了

- **v3（提交 `a2a8075`）曾断言：「"原文 + 追加更正"的链条完整留在同一档内」——这句是假的。**
  错版留此，更正如下。v3 把每个 `## ` 当原子，实测 **277 个相邻节对里有 164 个（59.2%）被分到
  不同档**，其中一条调查链被切成 5 个档（原 L3834 `character-gun` → L3842 `city-geometry` →
  L3848 `unsorted` → L3854 `engineering` → L3867 `ai-net-audio`）。根因：本文档的 `## ` 同时
  承担"事件标题"和"事件内小标题"两种角色，`改动` / `取证` / `判定` / `症状与根因` / `为什么`
  都不是独立小节。
- **v4 改成"续写标题粘回前一个事件"，但只扫 H2 ⇒ 把 H1 吞进了上一节正文。** 实例：L1713
  `## 📄 文档维护：AGENTS.md 压缩` 之后是 L1721 `# ✅ 未结案 #9 结案：mesh 着色器通过严格
  spirv-val`，再才是 L1723 `## 症状与根因` / L1733 `## 修法 build.rs::strip_workgroup…`——
  那两节属于这个 H1（mesh 着色器），v4 却把它们粘给了 AGENTS.md 那一节。
  v4 还另有一个静默 bug：Python 的 `\u` 转义**只吃 4 位十六进制**，`u'\u1f3af'` 被解析成
  `U+1F3A` + 字母 `f`，所以 emoji 集里所有平面外字符（🎯📊🔍🔧📄🛑🔎🪖）全是垃圾值，
  186 个边界只认出 134 个。**是"打印每个首字符的判定结果"这条自检抓到的**——不自检就会静默发出去。
- **v5 允许 H1 区域内的"事件标记 H2"自成事件**，实测 **186 个里有 118 个与父 H1 不同档**。
  实例：`# ✅ 追了两天的"池子坑"真根因（水平面绕序）` 这一个调查，被 `## 1. 症状与误诊`→
  `city-geometry`、`## 2. 定位链`→`engineering`、`## 4. 修复与判据`→`engineering`、
  `## 5. 教训`→`engineering` 拆成 3 个档。那里的 `1.` `2.` `4.` 是**一份报告的列表项**。
- **v6（本档）＝ H1 区域内不再下切**，只在"日期或轮次指纹不同"时才让 H2 脱离父 H1 自成事件。
